# Sales Performance Analysis

## Project Overview

Analyzed sales data using Excel, MySQL, and Power BI to evaluate business performance and generate meaningful insights.

## Tools & Technologies

* Microsoft Excel
* MySQL
* Power BI

## Key Activities

* Cleaned and analyzed sales data.
* Performed SQL queries for business analysis.
* Created KPI cards and interactive Power BI visualizations.
* Analyzed sales, profit, product categories, regions, and customer segments.
* Developed an interactive dashboard with filters.

## Key Deliverables

* Excel Sales Analysis
* MySQL Queries
* Power BI Dashboard

## Project Objective

To transform sales data into actionable insights that support business decision-making.
